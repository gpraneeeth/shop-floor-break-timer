# Shop-Floor Break Management & Productivity App

A lightweight, secure, and responsive web application designed for industrial plant operations and manufacturing floors to govern operator breaks, track compliance windows, and eliminate extended downtime.

## Features
* **Supervisor PIN Authentication:** Secure access control with hashed password storage.
* **Active Break Timers:** Multi-person real-time tracking across standard breaks and lunch periods.
* **Grace Period & Overtime Alerts:** Visual color-coding (Normal, Grace, Overtime) and audio chime notifications.
* **Audit Logging:** Persistent local session logging (`localStorage`) tracking actual break durations and status categories (On Time, Used Grace, Late).

## Tech Stack
* HTML5, CSS3, Modern JavaScript (ES6+), Web Audio API
